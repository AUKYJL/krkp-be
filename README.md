# TaxiFleet Pro Backend

Серверная часть приложения для управления таксопарком. Backend отвечает за авторизацию пользователей, разграничение ролей директора и водителя, работу с базой данных, управление таксопарками, автомобилями, водителями, рабочими днями и расчет аналитических показателей.

## Основной функционал

- регистрация и авторизация пользователей;
- разделение доступа по ролям: директор и водитель;
- управление таксопарками;
- управление автомобилями;
- управление водителями;
- учет рабочих дней и выручки;
- расчет аналитики по таксопаркам, автомобилям, водителям и маркам;
- расчет KPI: выручка, простои, выходы на линию, рейтинги и потери от простоев.

## Технологии

- Node.js
- NestJS
- PostgreSQL
- Prisma ORM

## Требования

Перед запуском необходимо установить:

- Node.js;
- npm;
- PostgreSQL.

## Установка

Перейдите в папку krkp-be:

```bash
cd krkp-be
```

Установите зависимости:

```bash
npm install
```

## Настройка переменных окружения

Создайте файл `.env` в папке krkp-be и укажите параметры подключения:

```env
DATABASE_URL="postgresql://USERNAME:PASSWORD@HOST:5432/DBNAME?schema=public"
JWT_SECRET="string"
PORT=5001
```

Пример локального подключения:

```env
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/taxi_park_db?schema=public"
JWT_SECRET="secret_key"
PORT=5001
```

## Настройка базы данных

После создания базы данных выполните миграции Prisma:

```bash
npx prisma migrate deploy
npx prisma generate
```

## Запуск проекта

Соберите проект:

```bash
npm run build
```

Запустите backend:

```bash
npm run start
```

После запуска сервер будет доступен по адресу:

```text
http://localhost:5001
```

## Проверка работы

После запуска можно проверить работу API через браузер, Postman или frontend-приложение. Если сервер успешно отвечает на запросы, backend настроен корректно.

## Порядок запуска всей системы

1. Запустить PostgreSQL.
2. Запустить backend.
3. Запустить frontend.
4. Открыть frontend в браузере.
5. Пройти авторизацию и проверить загрузку данных.
